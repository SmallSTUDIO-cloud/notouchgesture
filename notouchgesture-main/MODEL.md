# MediaPipe model asset

The build script downloads the official MediaPipe Gesture Recognizer task model into:

`app/src/main/assets/gesture_recognizer.task`

Source used by the build script:

`https://storage.googleapis.com/mediapipe-models/gesture_recognizer/gesture_recognizer/float16/1/gesture_recognizer.task`

The code uses the canned gesture labels `Open_Palm` and `Closed_Fist`.
